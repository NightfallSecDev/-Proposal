# 💕 Romantic Proposal Website

## How to Use

### 1. Customize
Open **`config.js`** in any text editor and fill in:

| Setting | What to do |
|---|---|
| `MY_NAME` | Your name |
| `HER_NAME` | Her name |
| `PHOTO_1–4` | Add photos (see below) |
| `SONG_URL` | Add a song (see below) |

### 2. Add Your Photos
- Create a folder called **`images/`** inside the `proposal/` folder
- Add 4 photo files named: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`
- They can be JPG, PNG, or WEBP

### 3. Add Your Song
- Create a folder called **`audio/`** inside the `proposal/` folder
- Add your song named: `our-song.mp3`
- Any MP3 file works. Music does **not** autoplay — she clicks play.

### 4. Open the Site
Just **double-click `index.html`** — no installation needed.

### 5. Share It
Upload to [Netlify Drop](https://app.netlify.com/drop) by dragging the entire `proposal/` folder:
- You'll get a free public link to send her
